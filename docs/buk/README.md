## סקריפטים

| קובץ | מה |
|---|---|
| `buk-companies-probe.ts` | קריאה בלבד: החברות הפתוחות למשתמש וכמה טפסי 101 בכל אחת. |
| `buk-101-batch.ts` | שליחה מרוכזת מ-`hr_101_queue` (`source='batch'`, `status='batch_queued'`, `note='company=<id>'`). ברירת מחדל דראי ראן; `?confirm=1` שולח; `?verify=1&ids=` קריאה בלבד (+`&save=1` שומר קישור ומזהה). |

- מפתח ה-Web API של buk לא נשמר בריפו (קיים בפונקציות הפרוסות). לפריסה מהריפו — secret בשם `BUK_FB_API_KEY`.
- סטטוס `batch_queued` ולא `await_confirm` — אחרת "כן" בוואטסאפ יתפוס את השורה וישלח דרך גג על הים.
- buk **מתעלם מה-`employeeId` שנשלח** ומקצה מזהה משלו — מאתרים את העובד אחרי שליחה לפי טלפון + חברה.
- `startWorkDate` = החתמה ראשונה ב-Shift (`shift_cells`), לא משמרת מתוכננת שלא בוצעה.
